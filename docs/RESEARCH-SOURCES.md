Public web content was inspected; no installers, binaries, package managers, agent sessions, or test fixtures were run. Repository README and release-note claims are attributed claims, not independent execution evidence. For mutable branches, exact observed commit/release is listed where available; before implementation, re-fetch and pin an immutable source revision.

## Evidence Policy for Future Work

1. The dated source version and exact file path/hash are recorded for every compatibility claim.

3. Verify exact release/tag signatures and hashes independently before any installation. A checksum hosted beside the download is not an independent trust root.
4. Run OS/platform tests only in a disposable isolated profile after Phase 1 is authorized. Do not use the user's configured agents/projects as test fixtures.
5. Record all unknowns as `unknown`/`needs_validation`; do not translate an unknown into support or a green indicator.
